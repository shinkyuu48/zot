## 🛠️ System Requirements

zot requires a stable environment to function correctly. Ensure your system meets these standards:

- Operating System: Windows 10 or Windows 11 (64-bit).
- Processor: Dual-core CPU or better.
- Memory: 4 gigabytes of RAM.
- Storage: 200 megabytes of free disk space.
- Internet: A stable connection for agent communication.

If your computer uses an older version of Windows, the application may experience performance issues or fail to launch. Verify your system settings before you start the installation process.

## ⚙️ Configuration Settings

The application includes a settings menu to adjust how you interact with AI agents. Open the settings by clicking the icon in the top right corner of the window.

- Theme: Select between light and dark modes to suit your workspace lighting.
- Agent Personality: Choose how the AI communicates during your sessions. Options include formal, concise, and creative modes.
- API Keys: You must provide a valid API key if you utilize external cloud services for processing. Store your key in the secure vault section within the settings menu.

The software saves these preferences automatically each time you update them. You do not need to restart the application to apply most changes.

## 🚀 Working with Agents

The terminal window serves as the primary interface. You type commands or questions here, and the agents respond in real-time.

- Start a Chat: Click the plus sign at the bottom of the window to initiate a new session with an agent.
- Task Delegation: You assign specific jobs to the agent by typing instructions such as "find files" or "summarize data." The agent processes these requests and provides output directly in your terminal.
- File Access: Grant the application access to specific folders via the file picker menu. This allows agents to read and edit files on your local machine.

Always review the outputs provided by agents before you commit to final changes. While the agent handles the heavy lifting, you retain full control over the final decisions.

## 🛡️ Security and Privacy

zot prioritizes your data safety. The application runs locally on your machine whenever possible. Sensitive information stays within your file system unless you explicitly choose to share it with an external service provider.

- Local Encryption: The application encrypts your configuration data.
- Controlled Access: You decide which folders the application can see.
- Offline Mode: You perform many tasks without an internet connection, though some AI features require external processing.

Check the logs folder within the installation directory if you encounter errors. These text files contain information about recent events and help you troubleshoot common issues.

Does the software track my keystrokes?
No. The application monitors only the command inputs you provide intentionally to the agent interface.
